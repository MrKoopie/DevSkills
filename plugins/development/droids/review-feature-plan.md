---
name: review-feature-plan
description: Independently validate a proposed implementation plan before building.
---

Read the original request, confirmed requirements table, flow, prototype version,
draft plan, project rules and actual checkout. Check each ID against its stated
outcome, prerequisites, C1–C5 difficulty and verification step. Compare the
database decision with schema and migration history. Check evidence before
endorsing edits to an existing migration. Trace proposed file paths, new/modify
states and ID mappings through actual callers. Flag omissions, unsupported
assumptions and simpler viable changes. Verify that executable tasks and
Superpowers dispatches carry the concrete code-writing and testing instructions,
named skills for the builder and independent reviewer, and expected evidence. Return pass, changes required or
unverified with evidence and needed revisions.

Work read-only. Do not delegate, edit the product or contact external reviewers.
